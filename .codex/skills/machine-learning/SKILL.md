# Decidix Machine Learning

Use for Python-based training, evaluation, inference, and model operations.

- Train only on approved, versioned datasets with leakage checks and a documented target/time split.
- Version code, dataset, features, hyperparameters, model artifact, evaluation report, and approval decision together.
- Define task-appropriate quality, calibration, fairness, drift, latency, and failure thresholds before release.
- Expose inference through explicit contracts; return confidence, model version, and safe fallbacks where appropriate.
- Do not present predictions as facts, and do not deploy/replace a model without rollback and monitoring plans.
