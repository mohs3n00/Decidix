# Decidix — خطة قفل جزء Flutter

> اتعملت 2026-10-29 بعد مراجعة الكود والإعدادات. كل بند مكتوب جنبه **الدليل** اللي اتلقى في المشروع، و**تعريف الخلاص** بتاعه.
> الباك والتصميم مش جزء من الخطة دي، إلا البنود اللي Flutter هيعملها لما هما يخلّصوا (قسم هـ).

## الوضع الحالي

- الـ 18 شاشة مبنية على الـ Figma وشغالة على الـ mock.
- طبقة الـ API جاهزة، والتبديل بين الـ mock والسيرفر بـ flag (`USE_MOCK`).
- 150 test كلهم ناجحين، و`flutter analyze` من غير issues.
- التطبيق اتبنى واشتغل على أندرويد (debug).

اللي ناقص تحت مقسوم لـ 5 مجموعات.

## هـ. مستني حد تاني

دي مش هتتعمل دلوقتي، بس مكتوبة عشان ما تتنسيش.

| البند | مستني إيه | شغل Flutter وقتها |

| تسجيل الدخول (Clerk) | قرار البدء + تصميم شاشة الدخول | `clerk_flutter`، وشاشة الدخول، ونربط `authTokenReaderProvider`، والـ 401 يرجّع للدخول، وقائمة على الـ avatar (خروج) |

| البلد | اسم البلد | الأسماء والعملة جايين من السيرفر. الـ mock بس هو اللي يتغير |

## تعريف "مقفول"

- كل بنود أ وب وج ود خلصت.
- `flutter analyze` نظيف، وكل الـ tests ناجحة، ومعاهم tests الخط الكبير والشاشات المختلفة.
- نسخة release موقّعة من أندرويد بتشتغل على موبايل حقيقي باسم وأيقونة Decidix، بالإنجليزي والعربي.

- الكود في git.
